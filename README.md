# mjayjoh.github.io

Personal website of **Minjae Joh** — live at **[mjayjoh.github.io](https://mjayjoh.github.io)**.

Built with [Jekyll](https://jekyllrb.com) on the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template and hosted on GitHub Pages.

## Navigating the site

The site is organized into tabs shown in the top navigation bar:

| Tab | URL | What's there |
| --- | --- | --- |
| **About me** (home) | `/` | Who I am and my research interests |
| **Education** | `/education/` | Degrees, honors, and coursework |
| **Experience** | `/experience/` | Research, teaching, and professional roles |
| **Leadership** | `/leadership/` | Fellowships and leadership experience |
| **Publications** | `/publications/` | Papers and talks |
| **CV** | `/cv/` | Skills, languages, and a downloadable PDF résumé |

The sidebar on the left shows my name, photo, location, email, and GitHub link.
